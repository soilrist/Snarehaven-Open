# 코드 스타일 (공통 원칙)

> 이름 접두어 표·언어별 세부 규칙·예시 코드는 엔진마다 다르다 → **`docs/engines/<엔진>.md` "코드" 절이 진짜 표.**
> 여기엔 C#(Unity) · C++/Blueprint(Unreal) · GDScript(Godot) 다 통하는 원칙만 적는다.

## 1. 이름 (공통 원칙)
- **타입(클래스·구조체·enum)은 PascalCase.** 세 엔진 다 같다.
- **줄임말 금지** (`dmg`, `plyr`, `mgr` X). 통용 약어만 허용: `UI`, `ID`, `HP`, `MP`, `XP`, `FX`, `AI` (두 글자는 대문자, 세 글자 이상은 첫 글자만).
- 필드 접두어(`m_`/없음/`_`), bool·이벤트 명명, private 관례는 엔진마다 다르다 — `docs/engines/<엔진>.md`.

## 2. 파일
1. **파일 하나 = 최상위 타입 하나** (가능한 한). 파일 이름 규칙(타입 이름 그대로 / 접두어 포함 / 씬과 짝)은 엔진별 — `docs/engines/<엔진>.md`.
2. 멤버 순서는 **상수 → static → 직렬화·노출 필드 → 나머지 필드 → 프로퍼티 → 이벤트/시그널 → 생명주기 함수 → public 메서드 → private 메서드** 를 공통 지향점으로 삼는다.

## 3. 모양
4칸 들여쓰기, 한 줄 120자 이내를 지향한다. 중괄호 스타일 등 세부 포맷은 각 엔진 공식 스타일 가이드를 따른다 (`docs/engines/<엔진>.md`, `.editorconfig` 가 경고).

## 4. 주석
- **"무엇"이 아니라 "왜".** `// 체력 감소` X → `// 무적 프레임 중엔 넉백만 (DESIGN 4.2)` O
- public API 는 한 줄 설명 주석 (C# `/// <summary>`, GDScript `##`, C++ 은 Doxygen 스타일).
- `TODO` 금지 → 할 일은 INBOX/ROADMAP. 왜: 다음 바퀴가 코드 속 TODO 를 못 찾는다. (검사기 경고 — 현재 Unity 만 지원)

## 5. 실제 버그를 막는 규칙 + 전체 예시
매 프레임 컴포넌트/노드 재검색 금지, 밸런스 숫자 하드코딩 금지, 파괴된 객체 null/유효성 검사, 이벤트·시그널 구독-해제 짝, 로그 태그 등 — 전부 `docs/engines/<엔진>.md` "코드 — 〔엔진〕 규칙" + "코드 — 예시" 절에 있다.
