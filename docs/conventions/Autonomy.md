# 자율 판단 규칙: 언제 혼자 정하고, 언제 묻나

## 한 줄 요약
**사람은 "무엇을·어떤 느낌으로·얼마나"만 정한다. "어떻게"는 AI가 정하고 기록한다.**

비유: 유능한 비서는 "회의실 어디 잡을까요?"를 묻지 않고 알아서 잡은 뒤 적어 둔다.
대신 **"예산 얼마까지 써요?"** 와 **"이 사람이랑 계약해요?"** 는 꼭 묻는다.

## 신호등 3색

### 🟢 초록: 혼자 정하고 바로 진행 (묻지 않는다)
되돌리기 쉽고, 플레이어가 느끼는 게임이 바뀌지 않는 것.
- 코드 구조, 클래스 나누기, 알고리즘, 사용할 Unity 기능
- 파일·폴더 위치, 이름 (컨벤션 문서대로)
- 조각 순서, 조각 크기, 테스트 방법
- 임시 그래픽(네모·원·단색 자리표시), 임시 효과음
- 패키지 선택 중 **무료·엔진 공식** 패키지
- 버그 고치는 방법
- **밸런스 숫자** — 체력·공격력·속도·확률·가격·경험치 곡선. 레퍼런스 게임의 값·장르 관례·이미 있는 숫자와의 비율을 근거로 **정하고**, `docs/DESIGN.md` §6 표에 `값 + 근거 한 줄` 로 적는다. 사람에게 묻지 않는다. `-1` 은 "아직 안 채움"일 뿐이라 커밋 전에 채운다. (DataDriven)
- **레퍼런스 게임의 시스템·구조·UI 흐름을 따라 만드는 것** (Reference.md) — 에셋 원본을 그대로 쓰는 건 🔴 5

→ 크게 방향이 갈리는 것만 `docs/decisions/` 에 결정 기록 한 장. 작은 건 커밋 본문 "왜" 한 줄로 충분.

### 🟡 노랑: 가정하고 진행 + INBOX 에 `확인` (막히지 않는다)
플레이 느낌에 영향이 있지만, 나중에 바꾸기 쉬운 것.
- 설계서가 애매한 부분의 해석 ("적이 플레이어를 보면 쫓아온다" → 시야 거리는? 방식은?)
- UI 배치, 연출 순서, 조작 키 배치
- 설계서·ROADMAP 에 없는 기능·콘텐츠를 만드는 것 (일시정지 메뉴 같은) — **항상 🟡. 🟢 로 조용히 넣지 않는다.** 왜: 루프가 설계서 밖 항목을 슬쩍 늘리면 사람이 뭐가 기획이고 뭐가 AI 생각인지 못 가른다.

→ 가장 무난한 해석으로 만들고, INBOX 에 `확인:` 을 남긴다. **사람이 답 안 해도 계속 진행.** `확인` 은 감독이 다음 검수 때 검산해서 닫는다 (맞으면 확정·삭제, 틀리면 `보정`, 방향이 걸렸으면 `질문`) — 사람에게 쌓아 두지 않는다.
→ 설계서 해당 절에 `〔가정: …〕` 표시를 남겨서 나중에 한눈에 찾게. 설계서에 없던 항목은 DESIGN §5 콘텐츠 목록에 `〔추가: 바퀴 n〕` 로 넣는다.

### 🔴 빨강: 반드시 묻는다 (그 부분만 멈추고 다른 조각으로)
1. **되돌리기 비싼 방향** — 장르, 시점, 아트 스타일, 타깃, 핵심 재미(필러), 조작 방식의 뼈대, 플랫폼, **레퍼런스 게임 자체를 바꾸는 것**
2. **돈·계정·밖으로 나가는 것** — 유료 에셋·서비스, 새 계정, 스토어 업로드, 외부 공개, 개인정보
3. **지우는 것** — 사람이 만든 파일·에셋 삭제, 이미 합친(main) 기능 제거
4. **권리** — 상업 이용이 확인 안 된 에셋·모델, 실존 인물·브랜드, **다른 게임의 에셋 원본(그림·소리·이름·대사)을 그대로 가져오는 것**. 시스템·구조·UI 흐름을 따라 만드는 건 🟢 (Reference.md)
5. **규칙 자체를 바꾸는 것** — 컨벤션 문서·검사기·훅·PROMPT 수정. 루프는 `질문`으로 제안만, 반영은 사람 승인 후 **감독**이.
6. **사람만 할 수 있는 것** — 계정 콘솔 화면 클릭, 결제, 엔진·SDK 설치, 기기 등록. ROADMAP 에 `[!] 사람:` 으로 표시하고 감독 보고 **맨 앞**에 올린다. 왜: 이게 안 풀리면 여러 마일스톤이 같이 막힌다.

## 묻는 방법 (사람 시간을 아끼는 법)
1. **모아서 한 번에.** 질문이 생길 때마다 하나씩 보내지 않는다. 감독이 모아서 보고 때 한꺼번에.
2. **고르기 쉽게.** 방향 질문은 선택지 2~4개 + 각 선택지의 결과 한 줄 + `추천`.
3. **답이 없어도 멈추지 않는다.** 빨강 항목이 걸린 조각은 건너뛰고 다른 조각을 한다. 할 조각이 전부 빨강에 막혔을 때만 STATUS 에 "막힘" 기록 후 스스로 멈춘다 (감독이 사람에게 묻고 다시 켬).
4. 사람이 **"알아서 해"** 라고 답하면: `추천` 채택 + 결정 기록. 숫자는 애초에 묻지 않는다 — 사람이 숫자를 **바꾸라고** 하면 그 값이 DESIGN §6 의 새 값이고 근거 칸에 `사람 지시 (바퀴 n)`.

## 스스로 점검 (판단 전 3초 질문)
- 이걸 **플레이어가 느끼나?** 아니면 🟢
- 느끼는데 **내일 바꾸기 쉽나?** 쉬우면 🟡 (숫자는 언제나 바꾸기 쉽다 → 🟢 로 정하고 근거를 적는다)
- **돈·지우기·방향·권리·규칙·사람만 할 수 있는 것** 중 하나면 🔴
