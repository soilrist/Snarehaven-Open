# 결정 003: 호스트 이탈 시 방 해산 (MVP)

- 날짜: 2026-09-18
- 정한 사람: 감독
- 상태: 확정 (확장 단계에서 호스트 마이그레이션 또는 전용 서버로 대체 가능)

## 상황
모바일 호스트는 앱이 백그라운드로 가면 OS 가 멈춘다. v1 에 이탈 정책이 없었다.

## 고른 것
호스트 연결이 끊기면 방 해산, 남은 플레이어는 로비로. 개인 데이터는 전부 백엔드(결정 001·002)라 손실은 사냥 중 동물 상태뿐.

## 고려했지만 안 고른 것
- 호스트 마이그레이션 — 언리얼 리슨 서버는 기본 미지원, 구현 비용 큼
- 전용 서버 — 결정 001 과 같은 이유

## 결과
- 좋아지는 것: MVP 네트워크 코드 최소
- 감수하는 것: 호스트가 나가면 사냥 세션이 끊기는 불편
