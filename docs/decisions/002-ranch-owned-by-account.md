# 결정 002: 목장은 계정 소유, 타이머는 백엔드

- 날짜: 2026-09-18
- 정한 사람: 감독
- 상태: 확정

## 상황
v1 은 호스트 로컬 세이브에 목장 상태를 두었다. 게스트가 다른 방에 들어가면 목장이 사라진다. 방치형 30분 타이머는 앱이 꺼진 동안도 돌아야 한다.

## 고른 것
목장 슬롯(`animalId`, `occupiedSinceUtc`, `stock`)을 PlayFab 플레이어 데이터에 두고, 수확 시 백엔드가 경과 시간으로 지급 개수를 계산(상한 5). MVP 는 남의 목장을 복제하지 않는다.

## 고려했지만 안 고른 것
- 룸 소유 목장 — 방 바꾸면 유실, 소유권 분쟁
- 로컬 타임스탬프 — 기기 시계 조작으로 즉시 수확 가능

## 결과
- 좋아지는 것: 리플리케이션 대상에서 목장 제거, 세이브 유실 경로 제거
- 감수하는 것: 수확마다 네트워크 왕복 1회
