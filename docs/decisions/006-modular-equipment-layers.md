# 결정 006: 옷 표현 방식을 부위별 모듈형 레이어로

- 날짜: 2026-09-21
- 정한 사람: 사용자 (Autonomy.md 🔴, 되돌리기 비싼 방향 — 리깅·에셋 파이프라인)
- 상태: 확정

## 상황
DESIGN 3.5 킥오프 질문 중 1번 "옷 표현 방식"을 감독이 두 안으로 냈다.
- A(감독 추천): 몸 전체 스킨 교체 — 옷 갈아입을 때마다 몸 메시 전체를 다른 텍스처/메시로 바꿔치기. 리깅 1벌만 있으면 되고 구현이 단순하지만, 옷마다 몸 전체를 다시 만들어야 해서 옷 종류가 늘수록 리깅·용량 비용이 커짐
- B: 부위별 모듈형 레이어 — 몸은 그대로 두고 상의/하의/신발 등 부위별 조각을 스켈레톤에 겹쳐 스킨. 부위 조합이 자유롭지만 각 조각이 베이스 스켈레톤에 맞게 스킨 웨이트를 가져야 해서 파이프라인이 더 무거움

감독은 A(전신 스왑)를 추천했으나, 사용자가 "부위별 모듈형 레이어로 간다"고 B를 직접 선택.

## 고른 것
**B. 부위별 모듈형 레이어.** `EquipSlot` 을 처음부터 상의/하의/신발 등 부위 단위로 나눠 설계 — DESIGN 3.5 의 기존 🟡 가정("옷 슬롯은 처음엔 1개")은 이 결정으로 폐기.

## 고려했지만 안 고른 것
- **A. 전신 스킨 교체** — 구현은 가장 쉽지만, 레퍼런스 게임처럼 부위별로 자유롭게 갈아입는 느낌(사용자가 원하는 레퍼런스 그 자체)을 처음부터 포기하는 안이라 기각. 나중에 부위별로 쪼개려면 이미 만든 전신 세트 에셋들을 전부 부위별로 다시 잘라야 해서 "되돌리기 비싼 방향"에 해당.

## 결과 (좋아지는 것 / 감수하는 것)
- 좋아지는 것: 옷 조각을 상/하의/신발 등으로 자유롭게 조합 — 레퍼런스 게임 레퍼런스에 더 가까운 결과. 나중에 옷 종류가 늘어도 부위별로만 추가하면 됨(전신 세트를 매번 새로 안 만들어도 됨)
- 감수하는 것: 리깅된 베이스 스켈레톤에 각 부위 조각이 스킨 웨이트를 맞춰야 해서, 리깅 방법(Mixamo 자동 vs Blender 수동)을 고를 때 "부위별 조각도 같은 스켈레톤에 맞게 스킨할 수 있는가"를 기준에 넣어야 함
