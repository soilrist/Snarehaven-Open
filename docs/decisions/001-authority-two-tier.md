# 결정 001: 판정 권위를 호스트/백엔드 2단으로 나눈다

- 날짜: 2026-09-18
- 정한 사람: 감독(사용자 위임 "알아서")
- 상태: 확정

## 상황
DESIGN v1 은 "플레이어 중 한 명이 호스트" 이면서 "서버 권위 검증 필수" 라고 써서 모순. 플레이어 호스트는 치트 가능한 클라이언트다.

## 고른 것
실시간 판정(동물 HP·포획·재료 드롭)은 호스트 리슨 서버, 재화가 걸린 판정(코인·젬·인벤토리 원본·목장 타이머·가챠·IAP)은 PlayFab 백엔드.

## 고려했지만 안 고른 것
- 전용 서버 — MVP 비용·운영 부담. 확장 단계 후보 유지
- 전부 호스트 권위 — 호스트가 코인 무한 생성 가능, 가챠 붙는 순간 경제 붕괴
- 자체 백엔드(Supabase/Nakama) — Unreal SDK·IAP 검증·가챠 로직을 직접 짜야 함. PlayFab 이 전부 내장

## 결과
- 좋아지는 것: 사냥 코인 드롭을 없애서 호스트 위조로 얻을 수 있는 건 재료·펫뿐
- 감수하는 것: MVP 부터 백엔드 의존(M2), 오프라인 플레이 불가
