# 결정 009: 탈것 = 도감 보상 목줄을 종과 바꾼다 (결정 007 대체)

- 날짜: 2026-09-24
- 정한 사람: 감독 (사용자 "레퍼런스 게임와 참고해" 위임 — 원본 규칙 우선, 다를 땐 기술 제약만 근거)
- 상태: 확정 (결정 007 을 대체)

## 상황
결정 007 은 "도감 100% = 탈것 탑승" 이었다. 원본(레퍼런스 게임)은 도감 보상으로 **목줄**(사냥 VN320 · 농사 VN303 · 낚시 VN319)을 받고, 목줄을 **탈것 종과 바꾼다**. 탈것도 8종(늑대·곰·여우·염소·무스·순록·울버린·스라소니)이고 고급 작업대에서 안장을 단다. 13.8(M13-03)이 목줄 3·안장 3 을 넣기로 했는데, 007 그대로면 목줄이 할 일이 없다.

## 고른 것
도감 카테고리(사냥·식물·낚시) 하나가 100% 가 되면 서버가 그 목줄을 계정당 한 번 주고, 잡화점에서 `ExchangeCollar` 로 목줄 1개를 탈것 종 하나와 바꾸며, **탈것 종을 1종 이상 가지면 탄다.** 안장은 고급 작업대 레시피로 만들고 `AttachSaddle` 로 종마다 1개 단다(모습뿐).

세부 숫자·화면은 DESIGN 8.3 개정 표가 정본이다.

## 고려했지만 안 고른 것
- **007 그대로(도감 100% 가 곧 탑승)** — 목줄·종 고르기가 원본과 달라지고, 목줄 3종이 쓸 곳 없는 아이템이 된다.
- **목줄마다 정해진 종(사냥 목줄 = 늑대 등)** — 원본 자료에 목줄↔종 짝이 없다. 목줄 3개로 8종 중 셋을 고르게 두는 편이 원본 "탈것과 바꾼다" 에 가깝다.
- **새 탈것 상인 NPC·전용 화면** — 잡화점 화면 한 줄로 충분하다(가장 작게).
- **안장에 속도 효과** — 원본에 효과 기재가 없다. 탈것 속도(8.3 ×5.0)를 흔들지 않는다.

## 결과 (좋아지는 것 / 감수하는 것)
- 좋아지는 것: 원본 흐름(도감 → 목줄 → 종 → 안장)과 같다. 목줄·종·안장 전부 서버(Player Data `codexCollars` · `mounts`)가 판정한다(CLAUDE.md 8).
- 감수하는 것: 탈것 전용 메시가 없어 종마다 동물 표 몸을 그대로 쓴다. 안장 셋이 같은 모습이다. 고른 종은 세션 안에서만 기억한다. 농사 목줄의 상자 출처는 M13-10 몫.
- 번호: 처음엔 008 로 썼으나 "결정 008" 은 이미 PvP 순서(사용자 확정 2026-09-22, DESIGN 8절 항목 7)가 쓰고 있어 감독이 합칠 때 009 로 옮겼다(2026-09-24).
