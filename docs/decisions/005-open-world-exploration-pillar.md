# 결정 005: 오픈월드 탐험을 메인 필러로, 목장은 하위 활동으로 재정의

- 날짜: 2026-09-21
- 정한 사람: 사용자 (Autonomy.md 🔴-2, 되돌리기 비싼 방향 — 장르/핵심 재미)
- 상태: 확정

## 상황
DESIGN v1.1 은 "사냥→포획→목장 방치생산"을 게임 전체의 한 줄 요약으로 뒀다. 사용자가
레퍼런스 게임와의 비교 질문에 이어 직접 방향을 정정: "탐험하며 넓히는 게임이 원하는 것"이며
목장은 메인이 아니라 농사와 같은 급의 여러 활동 중 하나다. M0~M4(사냥/포획/목장/멀티/모바일
빌드 점검)는 이미 84% 가량 완성돼 있어 되돌릴 것과 재사용할 것을 구분해야 했다.

## 고른 것
1. **월드 구조**: 존(zone)을 포탈/로딩존으로 잇는다(심리스 오픈월드 아님) — M3 의 로비→
   `ServerTravel`→맵 흐름을 그대로 재사용. 개발 비용이 가장 낮고, 심리스는 지금부터
   레벨 스트리밍·네트워크 relevancy 재설계가 필요해 기각
2. **목장 vs 농사**: 같은 "내 거점" 컴포넌트 안에서 슬롯 타입만 다르게(동물 생산 슬롯 / 작물
   슬롯). `URanchComponent`·백엔드 타이머 구조(3.2·4.5) 그대로 확장
3. **던전**: 새 맵/인스턴스를 만들지 않고 오픈월드 안 위험구역(몬스터 밀도만 높인 존)으로 시작
4. **탈것**: 지금 진행 중인 코어 루프(M1 사냥/포획, M2 목장) 마무리가 우선, 오픈월드 확장
   단계(가칭 M6)에서 착수 — 지금 코드에 영향 없음

## 고려했지만 안 고른 것
- **코어 루프를 통째로 재설계**(사냥/포획/목장 규칙 자체를 바꿈) — 사용자가 "목장은 그냥
  농사·목장 정도"라고 명확히 하며 기존 사냥/포획/목장 규칙 자체는 그대로 두는 쪽으로 확인됨.
  0번 요약과 8절 확장 순서만 바뀐다
- **심리스 오픈월드** — 탐험감은 더 크지만 M3 에서 이미 검증한 멀티플레이 코드(호스트 이탈·
  세션·`ServerTravel`)를 전부 다시 설계해야 해서 지금 단계에서는 기각. 존이 늘고 나서
  플레이 규모가 커지면 그때 재검토

## 결과 (좋아지는 것 / 감수하는 것)
- 좋아지는 것: M0~M4 코드·M5 진행 중인 비주얼 작업 전부 유지. ROADMAP 을 갈아엎지 않고
  M5 뒤에 확장 마일스톤(M6)만 얹는다
- 감수하는 것: 존 사이 로딩(포탈)이 있어 진짜 "이어진 하나의 섬"을 걷는 느낌은 아니다.
  플레이 규모가 커지면 다시 논의
