# 검사 모듈: Unreal  〔DRAFT — 사람 승인 후 DRAFT 표시 삭제〕

> 공통 원칙은 `docs/conventions/Verification.md`. 여기엔 **Unreal 에서 실제로 어떻게** 만 적는다.
> Unreal MCP(`ModelContextProtocol`)가 연결돼 있으면 MCP 명령, 없으면 커맨드릿/배치 모드 명령. 둘 다 안 되면 그 층은 **"못 함"**.

## 1층 — 기계 검사 (커밋 전 필수)
| 검사 | Unreal MCP | MCP 없을 때 |
|---|---|---|
| 컴파일 에러 0 | 로그 조회(Output Log) | `UnrealBuildTool <Target> <Platform> <Config> -Project=<uproject>` |
| 이름·폴더·자리표시 | — | `python3 tools/check_conventions.py --changed --engine unreal` |
| 유닛 테스트 (Automation Spec) | 로그로 결과 확인 | `UnrealEditor-Cmd.exe <uproject> -ExecCmds="Automation RunTests <필터>; Quit" -unattended -nullrhi "-ini:EditorPerProjectUserSettings:[/Script/ModelContextProtocolEngine.ModelContextProtocolSettings]:bAutoStartServer=False" "-ini:EditorSettings:[/Script/UnrealEd.CrashReportsPrivacySettings]:bSendUnattendedBugReports=False" -log` |
| 데이터 무결성 (ID 중복·빈 참조) | Automation Spec `FAutomationTestBase` 로 만든다 | 동일 |
| 빠진 에셋 참조(Broken Reference) | 커맨드릿(`ResavePackages` 등)로 스캔 | 동일 |

## 2층 — 동작 검사
- **Automation Spec/Functional Test**로 실제 입력을 넣는다: `FAutomationTestBase` 파생 테스트에서 `PlayerController` 로 키·버튼 입력을 흉내내거나, 레벨에 `AFunctionalTest` 액터를 배치.
- **UI 는 함수 직접 호출 금지** → `FSlateApplication::Get().ProcessKeyDown`/포인터 이벤트로 위젯 트리에 실제 이벤트 주입. 위젯이 다른 창에 가려져 있으면 히트테스트가 실패해야 정상.
- 대규모 자동 플레이는 **Gauntlet**(`RunUAT.bat RunUnreal ...`)로 — 여러 맵을 돌며 크래시·에러 로그를 모아 리포트.
- 테스트 이름: `<시스템>.<상황>.<기대>` (Automation Spec 관례, 점 구분: `Combat.ThreeHits.KnocksBack`)

- **기기(아이폰)에서 찍은 캡처를 꺼내는 법(M15-06, 루프#197):** `-SnareCapture=` 는 파일을 **앱 샌드박스 안**에 쓴다 — 맥에서는 `Saved/` 라 바로 열리지만 아이폰에서는 앱마다 따로인 컨테이너 안이라 Finder 로 갈 수 없다. ① **상대 경로로 준다**(`-SnareCapture=M15/cam.png`) — `ASnarehavenGameMode::ResolveCapturePath` 가 `Saved/` 밑으로 옮겨 적고, iOS 는 그 `Saved` 를 앱 컨테이너의 **Documents** 아래로 옮겨 앉힌다(엔진 `FIOSPlatformFile::ConvertToPlatformPath` — `bFileSharingEnabled` 가 꺼져 있으면 Documents, 켜면 Library 다. 우리는 안 켰다). 절대 경로를 주면 기기에서는 그 자리를 못 쓴다. ② 파일이 어디에 떨어졌는지는 게임 로그의 **`검사 캡처 요청: <경로>`** 줄이 글자 그대로 말해 준다. ③ 꺼내기: `python3 tools/ios/pull_captures.py`(케이블로 이은 아이폰 하나면 알아서 고른다 → `captures/device/` 에 푼다 · `--list` 붙은 기기만 · `--source Documents/…` 일부만 · `--dry-run` 명령만). 속은 `xcrun devicectl device copy from --domain-type appDataContainer`(Xcode 15+)이고 **앱이 개발 서명으로 깔려 있어야** 컨테이너가 열린다. **아직 실제 기기로 왕복해 보지는 못했다** — 맥에 붙은 아이폰이 없다(루프#197). 2층 `Snarehaven.Capture.PathLandsWhereWeCanFetchIt` 가 ①의 경로 규칙만 붙잡는다.
- **`-SnareCraftScreen[=Workbench]`**(DESIGN 8.10 제작 화면을 시작하자마자 연다 — 값이 `Workbench` 면 작업대 자리(작업대 레시피 + 놓기 탭), 없으면 배낭 탭(어디서나 레시피). 재료 있음/모자람이 보유 스냅샷 그대로 찍힌다. 재화는 안 움직이는 화면 전용 길이다. 로그 `검사용 제작 화면 열기 (-SnareCraftScreen=…)`. 작업자 C 8.10·8.11).
- **자기 캐릭터는 카메라 정중앙이라 손에 든 것이 머리에 가린다**(루프#127 실증 — M9-06 이전 코드에서도 같다, 회귀 아님). 장비를 눈으로 보려면 **중앙에서 벗어난 캐릭터**를 본다: 두 프로세스 검사에서는 상대 캐릭터가 비스듬히 보여 손이 드러난다. 무대도 고른다 — `L_Hunt` 스폰 자리는 돼지 무리에 파묻혀 안 보이고 `L_Ranch` 는 바닥이 비어 잘 보인다.
- **에디터 Play(PIE)에서만 나는 것을 보는 법(루프#172):** `tools/unreal/run_pie_check.py` 가 **사람이 Play 버튼을 누르는 길 그대로**(`ULevelEditorSubsystem::EditorRequestBeginPlay`) PIE 를 켜고 12초 둔 뒤 끄고 에디터를 닫는다. `-game` 은 PIE 가 아니라서(월드 종류가 다르고 `GIsEditor` 도 꺼져 있다) PIE 에서만 나는 결함은 재현되지 않고, 커맨드릿(`-run=pythonscript`)에는 틱 루프가 없어 PIE 가 진행되지 않는다 — 그래서 **에디터를 띄운 채** `-ExecCmds="py <절대경로>"` 로 태운다(`-RenderOffscreen -nosplash -unattended` 와 같이). **경로에 따옴표를 겹쳐 넣으면 안 된다** — `-ExecCmds="py \"<경로>\""` 로 주면 명령줄에는 그대로 실려도 파이썬이 한 줄도 안 돌아 `LogPython` 에 실행 줄이 안 뜬다(루프#172 에서 두 번 헛돌았다). 로그의 `[PIE검사]` 줄 사이를 읽는다.
- **애니메이션 클립을 재는 법(루프#139):** `tools/unreal/check_anim_loop.py` 가 클립의 **이음매 거리**(마지막↔첫 프레임 발 거리, 한 프레임 이동량과 비교한다)와 **디딘 발 흐름 중앙값·최소·최대**를 찍는다 — **최소가 0 이면 클립 안에 발이 멈추는 구간이 있다는 뜻**이고 루프 재생에서 "멈칫" 으로 보인다. 다듬는 것은 `tools/unreal/trim_player_anim_loops.py`(앞머리 정지 구간을 버리고 한 바퀴만 남긴다, 재실행 안전). 화면에서 확인할 때는 `-SnareMoveKey=`·`-SnareMoveScale=` 검사 중에만 켜지는 **프레임별 추적 로그**(`이동 추적 — 속도 … · 재생 속도 … · 클립 … 시각 … · 입력 크기 … · 발 흐름 …`)를 본다 — 1초 간격 위치 로그로는 프레임 단위 증상이 안 보인다. **`발 흐름`은 몸 기준 발 속도**라 캐릭터가 나아가는 속도와 무관하게 클립 안의 멈춤을 드러낸다.
- **눌린 키는 헤드리스에서 유지되지 않는다**(루프#56) — 창이 없어 포커스가 빠지면 한 번 누른 키가 씻긴다. `-SnareMoveKey=` 는 그래서 0.01초 타이머로 **눌려 있지 않을 때만** 다시 누른다(루프#850 — 눌린 키에 매 프레임 누름을 넣으면 걷기가 Idle↔Run 으로 뒤집혔다). 직접 입력을 넣는 검사를 새로 만들 땐 같은 함정을 본다.
- **데스크톱에서 가상 조이스틱을 보려면 `-faketouches` 를 붙인다**(루프#52). `Config/DefaultInput.ini` 의 `bAlwaysShowTouchInterface` 가 False 라 맥 `-game` 창에는 조이스틱이 안 뜨고, 뜨더라도 엔진은 마우스를 터치로 안 바꾼다. 데스크톱 이동 검사는 키보드(W/A/S/D·방향키)로 한다.
- **자동으로 잡을 수 있는 것은 코드로:** 분홍색(#FF00FF 근처, 누락 머티리얼 기본색) 픽셀 비율, 완전 흰/검은 화면, `UMG` 텍스트에 `TBD`·플레이스홀더 문자열 포함 여부 → Automation Spec 으로.

## 알려진 함정
- 에디터가 켜진 상태에서도 `-Cmd` 커맨드렛은 돈다(맥 UE 5.8.2, 감독 실증 2026-09-18 — 락 파일 없음). 단 **uproject 는 반드시 절대경로**: `UnrealEditor-Cmd Snarehaven.uproject …` 처럼 상대경로를 주면 UBT 가 엔진 `Binaries/Mac/` 기준으로 찾아 `Unable to find project file` 로 죽는다. 실패하면 로그의 `Exception:` 줄부터 읽고 원인을 쓴다 — 추측("에디터 켜져서") 금지.
- 커맨드릿 종료코드 1 은 곧 실패가 아니다. `-unattended` 에서 `Error:` 로그가 하나라도 있으면 끝에 `Failure - N error(s)` 를 찍고 1 로 나간다 — 현재는 EOS 아티팩트 미설정(🔴 EOS 제품 대기) 하나가 항상 찍힌다. GameFeatureData 에셋 매니저 규칙 누락은 `Config/DefaultGame.ini` 에 규칙을 추가해 2026-09-21 고쳤고, 그 원인이던 `AllToolsets` 플러그인은 API 자체가 이 엔진에 없어 같은 날 껐다(`docs/engines/unreal.md`). 통과 판정은 `Python script executed successfully` / 검사 스크립트의 자기 출력으로 한다.
- **루프가 띄우는 게임 실행은 전부 `-RenderOffscreen`, `-windowed` 금지(#1229)** — 사람 화면에 자동으로 움직이는 창이 뜨면 사람이 진짜 플레이로 착각한다(10-16 「나무 지나가면 자동 채집」). `-SnareAutoAttack`·`-SnareMoveKey=` 가 켜진 실행은 화면 위 가운데에 붉은 「검사용 자동 입력 중」 띠가 뜬다.
- `-nullrhi` 로 돌리면 렌더링이 없어 3층 캡처는 실패한다 — 캡처가 필요한 테스트는 `-nullrhi` 없이(또는 `-RenderOffscreen`) 돌린다.
- 셰이더 컴파일이 안 끝난 상태에서 첫 실행하면 첫 프레임이 전부 분홍색 — 캡처 전 셰이더 컴파일 완료를 기다린다(로그의 `Shaders Left to compile` 확인).
- `-RenderOffscreen` 첫 실행이 프레임 2쯤에서 몇 분간 안 넘어가는 건 정지가 아니라 콜드 셰이더 캐시 컴파일일 수 있다 — 프로세스가 CPU 를 계속 쓰고 있으면 기다린다. "로그가 안 는다" 만으로 정지라고 적지 않는다(#0008 은 60초에 포기해 "렌더 펌프 정지"로 잘못 기록했고, 캐시가 채워진 뒤 #0013 은 같은 명령이 12초에 끝났다).
- **헤드리스 실행에서 `Ensure`/크래시가 뜨면 `CrashReportClientEditor` 가 매번 새로 실행돼 이 맥 환경에서 자기가 죽고, macOS 가 그 죽음을 시스템 크래시 대화상자로 띄운다**(2026-09-21, `~/Library/Logs/DiagnosticReports/CrashReportClientEditor-*.ips` 3건, 바퀴#84 GameFeatureData ensure 직후). 원인은 UE 소스(`MacPlatformMisc.cpp:2407` `GenerateInfoAndLaunchCrashReporter`) — `-unattended` 로 돌면 `bSendUnattendedBugReports`(기본 true, `EditorSettings.ini` `[/Script/UnrealEd.CrashReportsPrivacySettings]`) 가 켜져 있는 한 ensure 하나에도 리포터를 새로 띄운다. `-ini:EditorSettings:[/Script/UnrealEd.CrashReportsPrivacySettings]:bSendUnattendedBugReports=False` 로 그 프로세스만 꺼서 막는다 — 모든 헤드리스 명령에 위 MCP 플래그와 같이 붙여 둔다.
- 바이너리 에셋(`.uasset`/`.umap`)은 커맨드릿·MCP 로만 다뤄야 리다이렉터가 안 깨진다 — `docs/engines/unreal.md` "언리얼 파일 다루기" 참고.
