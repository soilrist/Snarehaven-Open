# 사고 기록: STATUS 계획 줄을 만들기 전에 안 쓰고 끝에 한 번에 썼다

- 날짜 / 바퀴: 2026-10-03 / 루프#320 · #321 · #322
- 발견: 루프 자신(#321 기록에 "#320 과 같은 잘못" 이라 적음, #322 에 또)

## 무슨 일이 있었나 (사실만)
PROMPT ④-4 는 "STATUS 맨 위에 새 바퀴 머리줄 + 계획 한 줄" 을 ④-5 만들기 **전에** 쓰라고 한다. 세 바퀴 연속, 코드·시험을 먼저 만들고 STATUS 는 바퀴 끝 기록 커밋에서 계획·한 것을 한꺼번에 적었다.

## 몇 바퀴 동안 / 얼마나 번졌나
3바퀴. 결과물(코드·검사·커밋)에는 차이가 없다 — 바퀴가 중간에 끊겼다면 다음 바퀴가 "무엇을 하려 했는지" 를 STATUS 에서 못 읽었을 것이다.

## 왜 막지 못했나
- 규칙은 있었는데 PROMPT ④-4 가 ④-5 와 같은 파일 수정이라 "끝에 같이 쓰면 된다" 로 뭉개졌다. 검사가 없다(커밋 훅은 기록 커밋만 본다).
