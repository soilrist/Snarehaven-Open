# 레퍼런스 시트: 월드·환경 룩 (카메라·나무·바위·건물·물·불)

- 원본: 레퍼런스 게임 1.0 — 캡처 `_Source/reference/reference/steam_00.jpg`(거점 전경), `steam_02.jpg`·`steam_08.jpg`(밤 거점), `steam_10.jpg`(해변·배), `steam_17.jpg`(숲+해안), `steam_18.jpg`(눈+꽃), `steam_22.jpg`(집·풍차·태양광). 1920×1080 기준.
- 카메라: 고정 각 탑다운, 내려다보는 각 **약 55~60°**, 원근 있음(위쪽이 작아짐), 회전 없음. 화면 가로 폭에 캐릭터 약 25명 폭 = 시야가 넓다. 우리 720cm·60°(DESIGN 3.3)와 같은 결. 캐릭터 세로 = 화면의 7~8%.
- 지형·바닥:
  - 바닥은 단색 + **짧은 획 텍스처**(풀=진한 초록 짧은 빗금, 눈=연보라 점, 모래=주황 점) 성기게 뿌림. 타일 반복이 안 보이게 획 크기 8~12px.
  - 절벽은 계단식 층(2~3단), 옆면 회갈색 세로 줄무늬, 윗면 바닥색. 모서리 둥글게.
  - 물: 단색 파랑 `#3E7BD6`, 해안선에 **흰 점선 파도**(굵기 3px, 길이 20~40px) 2겹, 물속 바위는 연한 파랑 실루엣. 반사 없음.
  - 길: 흙색 얼룩(자연스러운 곡선), 포장 없음.
- 식생: 
  - **침엽수** = 원뿔을 3~4단 겹친 톱니 실루엣, 잎 색 2톤(위 밝음), 줄기 굵은 갈색 원기둥. 높이 캐릭터의 4~5배. 가을 존은 주황·노랑, 눈 존은 연보라 잎.
  - **활엽수** = 공 3~4개 뭉침. 덤불 = 공 1개 + 열매 점(주황/빨강 5~8개).
  - 꽃 = 잎 4장 + 흰/노랑 꽃잎, 2~3송이 무리. 바위 = 둥근 덩어리 회색 2톤, 3~5개 무리.
  - 배치 밀도: 화면당 나무 10~20 그루, 바위 무리 3~5, 빈 공간이 절반 이상 — 빽빽하지 않다.
- 건물·소품: 컨테이너(빨강·파랑·초록 단색), 나무 판자 데크·다리, 흰 울타리(말뚝 간격 넓게), 드럼통(파랑·빨강·노랑), 태양광 패널, 붉은 격자 안테나 탑, 지붕은 기와 무늬 3~4줄 단순화. **트라이앵글 적고 색은 한 면 한 색** — 우리 `SM_Building_*`·`MI_Building_*` 단색 머티리얼 방식과 같다.
- 조명·시간: 낮은 따뜻한 노란 태양광 + 긴 부드러운 그림자, 밤은 **남보라 `#5B4FA8`** 전체 톤에 모닥불·전구 점광원 주황(반경 캐릭터 3배). 모닥불은 불꽃 스프라이트 3~4겹 + 바닥 주황 라이트 + 위로 튀는 ✕ 불티.
- 색·서체·크기: 낮 풀 `#7BBF5A`, 눈 `#EAE6F5`, 가을 모래 `#F0C86A`, 물 `#3E7BD6`, 절벽 `#8C8378`. 우리 바닥(사냥터 linear 0.080/0.200/0.100 · 목장 흙 0.250/0.155/0.095, DESIGN 2.1)은 이 채도 범위 안.
- 우리 것과 다르게 할 점 (이유):
  - 레퍼런스 게임보다 살짝 따뜻하고 살짝 거친 텍스처(DESIGN 2). 획 텍스처는 유지하되 색온도만 +.
  - 목장존은 **덫/올가미 모티프** 소품(올가미 걸이·밧줄 울타리)을 반복 배치(DESIGN 2 차별화).
  - 존 단위 맵(DESIGN 1.3)이라 화면 밖 경계는 **바다**로 막는다 — 떨어지는 절벽 끝은 두지 않는다(사용자 2026-09-23, DESIGN 8.9 · 착수 전까지 지금 맵은 그대로).
- 검사 항목(3층): 카메라 각 55~60° 원근 · 바닥 획 텍스처 · 해안 흰 점선 · 침엽수 톱니 실루엣 3~4단 · 한 면 한 색 소품 · 빈 공간 절반 이상 · 밤이면 남보라 톤 + 주황 점광원.
