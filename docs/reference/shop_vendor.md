# 레퍼런스 시트: 상점·NPC 대화 패널 (뽑기 화면 `WBP_Gacha` 의 기준)

- 원본: 레퍼런스 게임 1.0 상인 화면 — 캡처 `_Source/reference/reference/steam_14.jpg`. 1920×1080 기준.
- 구성 (배낭 패널이 오른쪽에 **같이** 열린다 — 사고팔 때 내 칸이 보여야 하므로):
  - 패널 600×600, 화면 가운데 약간 왼쪽(x 630~1230, y 240~840). 크림색, 모서리 16px, 두 칸으로 나뉨(세로 구분선 회색 4px).
  - **제목 탭**: 연초록 알약 "Vendor"(재화 아이콘 + 글자 20px) 패널 왼쪽 위에 걸쳐 위로 튀어나옴 — 배낭의 진갈색 탭과 같은 규격, 색만 다름(상점=초록).
  - **왼쪽 칸 = 거래 목록** (행 높이 68px, 8행, 스크롤바 오른쪽 세로 회색):
    - 사는 것: `가격(초록 굵게 26px + 위첨자 단위)  >  아이템 원판 52px`
    - 파는 것: `아이템 원판  >  가격` — **화살표 방향이 곧 돈의 방향**. 버튼 없음, 행 자체를 누른다.
  - **오른쪽 칸 = NPC 명함**: 빨간 알약에 NPC 이름 20px 흰색 → 그 아래 회색 좌표 16px → 본문 16px 진갈색, 줄간 1.4, 문단 사이 한 줄 띄움, 마지막 줄 서명("-Tim"). 편지 느낌.
- 색·서체·크기: 가격 초록 `#3DBB63`, 이름 알약 빨강 `#E8514F`, 나머지 배낭 시트와 같음.
- 조작 흐름: NPC/기계 근처 프롬프트 → 패널+배낭 동시 열림 → 행 탭 1회 = 거래(확인 창 없음, 즉시) → 배낭 칸이 바로 갱신 → 밖 탭 = 닫힘. 단계 수 2.
- 우리 것과 다르게 할 점 (이유):
  - **뽑기 화면(M7-04)**: 왼쪽 칸 행 = `등급 원판(색) · 등급 이름 · 확률 %`(법적 표시, DESIGN 10.4) 위에서 아래로 등급 순, 그 아래 행 2개 = `1회 뽑기 · 비용` / `10연차 · 비용` 를 사는-것 규격(가격 > 아이템)으로. 오른쪽 칸 = "올가미 기계" 명함 + 천장·중복 환급 설명문(편지체). 확률 숫자는 `DT_GachaRates` 에서만.
  - 거래 즉시 반영은 **백엔드 응답 뒤**(CLAUDE.md 8) — 응답 전엔 행을 눌린 상태로 두고 스피너 없이 잠깐 잠근다.
  - 좌표 줄은 존 이름으로.
- 검사 항목(3층): 두 칸 패널 · 왼쪽 목록이 "가격 > 아이템" 행 · 오른쪽 명함+본문 · 제목 탭이 위로 걸침 · 배낭이 오른쪽에 같이 열림.
