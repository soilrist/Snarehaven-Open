# 레퍼런스 시트: 플레이어 캐릭터 (비율·장비 착용·옷장 화면)

- 원본: 레퍼런스 게임 1.0 — 캡처 `_Source/reference/reference/steam_06.jpg`(옷장 클로즈업), `steam_05.jpg`·`steam_16.jpg`(낚싯대 든 탑다운), `steam_01.jpg`(총 든 여러 명), `steam_19.jpg`(모자·배낭 차이). 1920×1080 기준.
- 비율·실루엣:
  - **2.5등신**. 머리가 전체 높이의 약 40% — **공이 아니라 모서리 둥근 상자/짧은 원기둥**(가로 > 세로, 앞면이 세로로 평평). 감독 영상 확인 10-04: 트레일러 `LRcu-stJ994` 0:06 모닥불·0:34 배(위에서 봐도 얼굴 보임), `Qln6lR8cuCc` 10:12 대기. 몸통은 짧은 통, 팔은 짧은 막대(손가락 없음, 손끝 둥글게), 다리는 짧고 굵음. 목 없음 — 머리가 몸통에 바로 얹힘.
  - 탑다운 720cm·60° 카메라(DESIGN 3.3)에서 세로 약 110~135px — 레퍼런스 게임도 1080p 화면에서 캐릭터 세로 ≈ 80px(`steam_05`), 화면 높이의 7~8%.
  - 얼굴: 평평한 앞면을 거의 꽉 채운다 — **큰 눈 2개가 앞면 가운데 높이**, 짧은 눈썹, 작은 입. 점 눈·아래쪽 작은 얼굴 금지(55° 카메라에서 정수리만 보이는 원인). 볼터치 없음. 피부 톤 몇 가지.
  - 눈 크기(2026-10-19 사람 「레퍼런스 게임도 눈이 크잖어」, 검색 이미지 대조): 레퍼런스 게임 = 진한 큰 타원 눈이 얼굴 높이 1/4 안팎, 위 눈꺼풀이 덮인 졸린 눈 + 흰 반짝임. **우리 것은 겉모습을 다르게 — 애니풍으로 더 크게**(얼굴 높이 약 1/3, 세로 긴 타원, 눈꺼풀 덮지 않은 또렷한 눈, 반짝임 1~2개). 위 카메라에서 눈이 얼굴에서 제일 먼저 보여야 한다.
  - 정수리는 항상 머리카락 덩어리 또는 모자가 덮는다 — 민머리 살색 정수리 금지.
  - 대기 자세: 거의 가만히 서고 **팔은 몸통 옆에 축 늘어진다**(팔꿈치 거의 펴짐, 손은 허벅지 옆). 주먹 든 복싱 자세 금지.
  - **평면 셰이딩 + 부드러운 그림자**, 외곽선 없음. 색은 2~3톤 뿐(옷 한 색 + 포인트 한 색).
- 장비가 **실제로 보인다** (DESIGN 3.5 의 이유):
  - 등에 **배낭**(몸통 뒤 작은 상자, 옷과 다른 색) — 항상.
  - **머리**: 모자·고글·귀마개 등 1슬롯. 고글은 이마 위.
  - **몸**: 상의(재킷/티) + 하의 + 신발 — 3슬롯. 캡처 06: 회색 방한복 + 파란 오리발.
  - **손**: 낚싯대(오른손, 앞으로 45°) · 소총(양손, 몸 앞 가로) · 도끼. 들고 있는 것이 곧 현재 도구. 우리 `Socket_Weapon`(오른손) + `Socket_Tool`(왼손, M9-01).
- 옷장 화면(`steam_06.jpg`, 우리 M9-03 부위별 장비 화면 기준):
  - 왼쪽 2/3 = 캐릭터 3D 뷰(측면, 바닥 그림자). 캐릭터 둘레에 **둥근 크림 버튼 5개**(지름 100px, 아이콘 갈색): 머리(위 왼쪽) · 얼굴(왼쪽 가운데) · 몸/상의(오른쪽, 티셔츠 아이콘) · 하의(왼쪽 아래, 사람 아이콘) · 회전(아래 가운데, ↻). 부위 버튼을 누르면 오른쪽 목록이 그 부위로 필터.
  - 오른쪽 1/3 = 크림 패널 540×800, 위에 탭 2개 알약("내 아이템" 보라 / "전체" 초록), "보유 아이템" 소제목 16px, **격자 8열**(칸 56px, 간격 8px) 색 원판 아이콘, 스크롤바 오른쪽, 맨 아래 보라 버튼 "상점 열기". 오른쪽 위 구석 "나가기" 크림 버튼.
- 색·서체·크기: 배낭 시트와 같음. 원판 색 = 등급.
- 조작 흐름: 옷장 오브젝트 프롬프트 → 화면 전환(월드 가림) → 부위 버튼 → 목록에서 탭 = 즉시 착용(미리보기 = 착용) → 나가기. 단계 수 3.
- 우리 것과 다르게 할 점 (이유):
  - 베이스 메시는 바르코 생성 `SK_Player_Body`(DESIGN 3.5) — 비율만 위 2.5등신에 맞춘다. 레퍼런스 게임/동물의숲 얼굴 그대로 금지(§1 표절 비판 이력, Reference §5).
  - 옷 색은 DESIGN 2 "따뜻한 파스텔, 레퍼런스 게임보다 살짝 따뜻하게".
  - 장착은 로컬 시각 효과, 소유는 백엔드(DESIGN 3.5).
- 검사 항목(3층): 2.5등신·상자형 머리·게임 카메라에서 두 눈 보임·팔 늘어뜨림 · 배낭이 등에 보임 · 든 도구가 손에 보임 · 외곽선 없음 평면 셰이딩 · (옷장) 부위 버튼이 캐릭터 둘레 원형 · 목록 8열 원판.
