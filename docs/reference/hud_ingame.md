# 레퍼런스 시트: 인게임 HUD (사냥터·목장 공통 상시 표시)

- 원본: 레퍼런스 게임 1.0 인게임 화면 — 캡처 `_Source/reference/reference/steam_05.jpg`(낚시+배낭), `steam_13.jpg`(경고 토스트+범례), `steam_16.jpg`(알림 카드 2장), `steam_19.jpg`(플레이어 이름표). 1920×1080 기준. 우리 720p 는 ×0.67.
- 구성 (화면 네 귀퉁이만 쓰고 가운데는 비운다):
  - **왼쪽 위**: 빌드 버전 글자(작게, 흰색+그림자) → 우리는 `Snarehaven <버전>` 만. 그 아래로 **알림 카드**가 세로로 쌓인다(최대 2장 보임): 크림색 카드 300×70, 왼쪽 아이콘 48px, 제목 굵게 18px + 설명 14px, 카드 오른쪽 위 작은 색 점(빨강=새 발견·파랑=아이템). 예: "새 발견! 도감이 갱신됨" / "무지개 송어 · 에픽 · 설명 한 줄"
  - **왼쪽 위(오류)**: 빨간 알약 토스트 480×34, 흰 글자 14px, 왼쪽 ⚠ 아이콘. 한 줄, 3초 뒤 사라짐(눈대중). 예: "남의 땅에는 놓을 수 없습니다"
  - **오른쪽 위**: 남색 알약 170×45, 📍 아이콘 + 좌표 "10°N / 8°E" 굵게 20px 흰색. → 우리는 **존 이름 + 재화 잔액**(`SnareBalanceHud`, DESIGN 3.4·10.1) 자리. 잔액은 레퍼런스 게임 배낭 하단 바 규격(inventory 시트) 그대로.
  - **왼쪽 아래**: 빨간 알약 145×50, 왼쪽에 들고 있는 무기 아이콘 40px + 흰 숫자 28px 굵게 ("100" = 탄약/내구). → 우리는 **들고 있는 무기·도구 + 내구/HP** 자리. 조이스틱은 그 위쪽 빈 공간(DESIGN 3.3).
  - **오른쪽 아래**: 노란 번개 ⚡ 10칸 가로 한 줄(각 20px, 간격 4px) = 기력. 소진분은 회색. 그 위에 작은 정사각 아이콘 44px(빠른 슬롯/현재 도구, `steam_01.jpg`·`steam_09.jpg`). → 우리는 공격·포획 버튼 자리(DESIGN 3.3 확정: 포획 오른쪽 아래, 공격은 그 왼쪽). 기력 줄은 M9 이후 스태미나가 생기면 같은 규격.
  - **월드 위 오버레이**:
    - 플레이어 **이름표**: 색 알약(높이 22px, 좌우 여백 8px, 글자 14px 굵게 흰색) 머리 위 약 40px. 알약 색은 플레이어마다 다름(노랑·초록·파랑·분홍). 자기 것도 보인다.
    - **상호작용 프롬프트**: 대상 옆 작은 크림 카드 "❗[E]" 36px — 키 글자만 바꿔 우리는 버튼 아이콘. 대상이 없으면 안 보임.
    - 플레이어 발밑 **얇은 진행바**(폭 60px, 높이 6px, 회색 바탕+흰 채움, `steam_16.jpg` 낚시 중) = 행동 진행. → 포획·채집 진행에 그대로.
- 색·서체·크기: 패널 크림 `#F5EBD2`(눈대중) — 우리 `UI_ButtonBase #F2E4C9` 와 같은 계열이라 그대로. 강조 빨강 `#E8514F`, 남색 `#2B2D5C`, 번개 노랑 `#F5D33B`, 글자 진갈색 `#4A3826`(우리 `UI_TextOnButton`). 서체: 둥근 기하학 산세리프 굵게(Nunito 급) → 우리 `Font_UI_Jua`. 모든 패널 모서리 둥글게 12~16px, 테두리 없음, 그림자 없음.
- 조작 흐름: HUD 는 누르는 게 없다(정보만). 상호작용은 월드 대상에 붙는 프롬프트 하나 → 버튼 1회. 배낭 열기는 오른쪽 세로 탭(inventory 시트).
- 우리 것과 다르게 할 점 (이유):
  - 하이라이트된 동물 이름·HP 바는 **화면 위 가운데**(DESIGN 3.3 확정 — 레퍼런스 게임는 총이라 대상 HP 바가 없다). 규격은 알림 카드와 같은 크림 카드 300×56, 이름 18px + HP 바 240×10.
  - ~~좌표 대신 존 이름·잔액~~ → 2026-09-25 레퍼런스 게임 영상 기준으로 **뺐다**: 영상 화면엔 좌표·잔액·버전 글자가 없다. 잔액은 배낭 판 아래 바에서만(DESIGN 3.3 「화면 비우기」).
  - 가상 조이스틱은 쉴 때 안 보이고 누를 때만 뜬다(영상 화면에 스틱 원이 없다).
  - 공격·포획 버튼은 둥근 반투명 원 → **크림 네모 100px**(모서리 14, 진갈색 글자) — 오른쪽 아래 빠른 슬롯 네모(44px@1080)를 엄지 크기로 키운 것(2026-09-25 영상 기준).
  - 모바일이라 키 글자([E], [F1]) 대신 버튼 아이콘. 버튼은 숨기지 않고 꺼 둔다(DESIGN 3.3).
- 검사 항목(3층): 네 귀퉁이 배치 같음 · 알림 카드가 왼쪽 위에 세로로 쌓임 · 이름표가 색 알약 · 발밑 진행바 있음 · 가운데 비어 있음.
