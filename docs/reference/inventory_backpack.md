# 레퍼런스 시트: 인벤토리(배낭) 패널

- 원본: 레퍼런스 게임 1.0 배낭 — 캡처 `_Source/reference/reference/steam_05.jpg`(꽉 찬 배낭), `steam_16.jpg`(거의 빈 배낭), `steam_14.jpg`(상점과 나란히). 1920×1080 기준.
- 구성:
  - 위치 **오른쪽 가장자리**, 세로 가운데보다 약간 위 (x 1283~1595, y 320~760 → 패널 312×440). 월드는 그대로 보이고 게임은 멈추지 않는다(멀티).
  - **제목 탭**: 진갈색 알약 "Backpack" 130×50, 패널 왼쪽 위 모서리에 걸쳐 **위로 튀어나옴**(패널보다 20px 위). 글자 흰색 20px 굵게.
  - **격자 4열 × 5행 = 20칸** — DESIGN 3.3 "초기 20칸" 과 정확히 같다. 칸 52px 정사각, 간격 12px, 모서리 8px. 빈 칸은 연회색 `#E9E0C8` 둥근 네모(테두리 없음).
  - **아이템 칸**: 색 원판(지름 52px) 위에 아이템 그림. 원판 색 = 등급: 초록 `#6CCB8A` 일반, 주황 `#F0895A` 고급(?), 보라 `#A46BE0` 에픽(캡처 16 "Epic" 카드와 같은 색). 수량 숫자는 캡처에 없음(스택 아님 — 우리는 오른쪽 아래 14px 숫자 추가).
  - 장착/사용 중 표시: 아이템 원판 오른쪽 위 작은 ⚡(`steam_14.jpg` 자루 아이템) — 우리는 "장착 중" 표시로 같은 자리.
  - **왼쪽 세로 탭 3개**(패널 밖, 패널 왼쪽 -60px, 위에서부터): 배낭(선택 시 노란 테두리) · 장비/도구(망치+톱 아이콘) · 도감(파란 책). 각 52px 크림 네모. → 우리: 배낭 · 장비(M5-06c 장비 버튼이 여기로) · 도감(M10 `CODEX.md`).
  - **하단 바**: 패널 안쪽 아래 260×48 연한 알약, 왼쪽 재화 아이콘(초록 지폐 28px) + 숫자 20px 굵게 + 오른쪽 끝 `>` (눌러 상점/거래로). → 우리 스네어 코인. 젬은 같은 바를 한 줄 더.
- 색·서체·크기: 패널 크림 `#F5EBD2`, 제목 탭 `#5A3E36`, 글자 `#4A3826` — 우리 팔레트(DESIGN 2.1) 안에서 명도만 파생. 모서리 16px. 서체 `Font_UI_Jua`.
- 조작 흐름: 세로 탭(배낭) → 패널 열림(월드 계속) → 칸 탭 → (레퍼런스 게임는 우클릭 메뉴) 우리는 칸 아래 툴팁 카드 + 사용/장착/버리기 버튼 3개 → 다시 탭 닫힘. 단계 수 2.
- 우리 것과 다르게 할 점 (이유):
  - 스택 수량 숫자 표시(DESIGN 3.3 스택 상한 99, 재료가 쌓인다).
  - 등급 색은 우리 `DT_ItemTable` 의 등급 열로 결정(코드 상수 금지, DataDriven).
  - 인벤토리 원본은 백엔드, 여기서는 캐시만 그린다(CLAUDE.md 8).
- 검사 항목(3층): 오른쪽 가장자리 · 4×5 격자 · 제목 탭이 위로 걸침 · 왼쪽 세로 탭 3개 · 하단 재화 바 · 아이템은 색 원판 위 그림(네모 아이콘 아님).
