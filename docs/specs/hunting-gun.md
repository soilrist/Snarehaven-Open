## 1. 합격 기준 (한 문장)
> 잡화점에서 산 권총을 들고 탄약을 넣으면(재장전) HUD 에 `7/25` 가 뜨고, 공격을 한 번 누를 때마다 총구 불꽃과 함께 빛나는 총알이 동물까지 날아가 맞은 자리에 하얀 별 튀김이 일며 동물 체력이 깎이고, 탄창이 비면 더 나가지 않으며, 사람·펫·목장 동물에게는 피해가 0 이다.

## 2. 플레이어가 보는 것
- 입력: **새 쏘기 버튼 없음** — 권총을 들면 오른쪽 아래 공격 버튼이 그대로 「쏘기」(한 번 누름 = 한 발, 반자동 — 누르고 있어도 연사 없음, 3.1 「공격 간격」 규칙 그대로). 공격 버튼 **왼쪽** 작은 「재장전」 버튼(72 이상, M38, 아랫변 맞춤) — 포획·공격 위는 아이콘 기둥·존 이동 버튼 자리라 겹친다(M39-06b 루프#578 캡처). 스페이스바도 같은 `BeginAttack`.
- 조준: **조준 없음(3.3 자동 상호작용 그대로)** — 사거리 안에서 앞쪽 부채꼴(±60°) 가장 가까운 사냥 동물에게 몸을 돌려 쏜다. 없으면 바라보는 쪽으로 똑바로 쏘고 사거리 끝 땅·처음 막는 나무·바위에 박힌다.
- 화면: 들면 두 손 권총 겨눔 자세 → 누르면 반동 클립(0.15초 안) + 총구 불꽃(1~2프레임) + 총소리 → **빛나는 총알(노란 점 + 짧은 꼬리)이 총구에서 과녁까지 실제로 이동**(순간 선 긋기 금지) → 도착 순간 맞은 자리 튀김(동물 = 하얀 별, 땅 = 흙먼지, 나무 = 나무 부스러기, 바위 = 돌 부스러기) + 총알 사라짐 → 동물이면 기존 피격 깜빡임·숫자. 빗나가면 사거리 끝 땅에 먼지.
- 그림 모양(루프#576 M39-05, 연출 튜닝값 — 밸런스 아님): 총구 = 몸 가운데에서 쏘는 쪽 앞 50cm·위 20cm · 불꽃 22cm 0.05초(30fps 1.5장) · 총알 점 14cm · 꼬리 굵기 10cm, 길이 = 행 속도 × 0.04초(권총 160 · 소총 240 — 3절 표와 같음, 루프#584 M39-07b 감독 「두께 ≥4px · 꼬리 ≥60px」) · 닿는 순간 퍽 = 반투명 공(가운데 진하고 가장자리 0, `M_ImpactPuff`) 70 → 85cm 0.08초에 불투명도 1 → 0(동물 흰색, 카메라 쪽 50cm 앞 — 루프#585 M39-07c) · 튀김 조각 20개 16cm 0.35초(동물 피격 파편과 같은 수명, 동물이면 6개 털빛) · 빗나감은 사거리 끝 아래 500cm 안 땅에 박힘(못 찾으면 허공 끝) · 막힘 종류 = 채집물은 필요한 도구(곡괭이 → 돌, 그 밖 → 나무), 그 밖은 면이 위를 보면(법선 Z ≥ 0.7) 땅 · 서 있으면 돌. 발광은 `M_HitFlash` 동적 인스턴스(새 에셋 0). 🟡 감독 캡처 대조(M39-07)에서 고칠 수 있음.
- HUD: 재장전 버튼 왼쪽 탄 글 `탄창/가방 탄약`(예 `7/25`) — 한 줄 `[7/25][재장전][공격][포획]`. 권총을 들었을 때만 보인다.
- 실패·예외:
  - 탄창 0 → 누르면 「찰칵」 빈 소리 + 탄 글 빨강 깜빡, 총알 안 나감(서버 요청 0). 가방 탄약이 있으면 재장전 버튼이 깜빡여 안내.
  - 가방 탄약 0 + 재장전 → 서버 `not_enough_items` → 알약 「탄약이 없다 — 잡화점」(1.4 기존 「…가 필요」 알약 길).
  - 재장전 중(1.2초) 누름 무시, 재장전 중 도구를 바꾸면 재장전 취소(이미 서버가 뺀 탄은 탄창에 들어간 것으로 — 응답 기준).
  - 사람·펫·목장 동물·탈것은 총알이 **지나간다**(맞음 판정에서 뺌, 튀김 없음).
  - 거점(목장 존)·실내에서는 쏘기 꺼짐(공격 버튼이 원래 그 존 동작) — 🟡 목장 동물 오사 방지.

## 5. 권위 (규칙 8 · DESIGN 4.1)
- **탄약 = 인벤토리 → 백엔드.** 재장전 때만 CloudScript `LoadAmmo` 를 부른다: 서버가 `min(탄창 - have, 가진 탄약)` 발을 빼고 `loaded = have + removed` 를 돌려준다. 클라는 응답의 `loaded` 로만 탄창을 채운다(응답 전 HUD 안 바꿈).
- **쏘기·명중 = 호스트.** 탄창 남은 수는 호스트 컴포넌트가 들고 복제한다. 게스트는 응답 `loaded` 를 `Server_SetLoadedRounds(n)` 로 알리고 호스트는 `0..MagazineSize` 로 자른다 — 🟡 게스트가 응답보다 큰 수를 말할 수 있으나 PvE 에서 이득은 「동물 HP 더 깎기」 뿐이고 드롭·재화는 기존 호스트 판정·백엔드 대기열 그대로라 재화 경로가 없다(4.8). PvP 단계에서는 서버 서명값으로 바꾼다.
- 탄창 속 탄은 **세션 동안만** 남는다(쏠 때마다 서버를 안 부르니 저장 값이 낡는다). 나가면 탄창 안 탄(최대 7발 ≈ 1.4코인)은 사라진다 — 🟡.
- 쏘기는 서버 호출 0 — 동물 피해·드롭은 기존 근접 경로(`ApplyDamage` → 죽음 → `OnAnimalKilled` → 대기열).
