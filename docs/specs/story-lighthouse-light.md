# 기능 명세: 등대 점등 — 5장을 끝낸 계정에게만 밤마다 도는 불빛

- 상태: 초안
- 마일스톤: 메인 스토리 ⑤ · 범위(커밋 scope): `story`
- DESIGN 연결: 의뢰 줄기 절 · `docs/STORY.md` 2절 「잠든 등대」·4절 5장 5단계·5절 · INBOX 지시 「메인 스토리 퀘스트」 ⑤ · `docs/specs/story-fogbuck.md` 7절이 미룬 「등대 점등 연출」

## 1. 합격 기준 (한 문장)
`FStoryView.bDone`(25단계까지 끝) 인 계정의 월드에는 등대 탑이 서고 밤(`NightAmount`)에만 불빛이 20초에 한 바퀴 돌며, 끝내지 않은 계정의 월드에는 탑이 꺼진 채(불 없음) 서 있다.

## 2. 플레이어가 보는 것
- 화면: 섬 한가운데 언덕 위의 흰 줄무늬 등대 탑. 5장 전에는 창이 어둡고 밤에도 불이 없다. 5장을 끝내면 밤마다 꼭대기에서 따뜻한 빛줄기가 돌고 탑 창이 켜진다. 낮에는 불이 꺼져 있다(밤에만 켜지는 기존 `SnareNightLight` 태그 규칙).
- 조작: 없음(보기만). 가까이 가도 누를 것은 없다 — 25단계 「불 켜기」는 서버 판정(`report`)이 이미 넘기고, 이 조각은 그 결과를 월드에 비추는 것뿐이다.
- 실패·예외: 서버 답이 오기 전(`View` 없음)은 꺼진 채로 둔다. 답이 `bDone` 으로 바뀌면 그 자리에서 낮밤 규칙대로 바로 켠다. 멀티에서는 각자 자기 계정의 `bDone` 으로 자기 화면만 켠다(복제하지 않는 장식 — 재화·보상이 없어 DESIGN 4.1 권위 2단과 무관).

## 3. 숫자 (🟡 — DESIGN 에 구현 조각에서 `항목 | 값 | 근거` 표로 옮긴다)
| 이름 | 값 | 근거 |
|---|---|---|
| 빛줄기 한 바퀴 | 20초 | 실제 등대 렌즈 회전 주기 10~30초의 가운데. 밤 8분(`NightSeconds`) 동안 24바퀴 |
| 빛줄기 도달 | 5000 uu(50m) | 모바일 시야 거리 안에서 멀리서도 보이되 `SnareWorldDensity` 의 먼 곳 컷 안 |
| 빛 개수 | 스포트 1개 + 창 점광 1개 | 모바일 동적 광원 예산 — 기존 `SnareNightLight` 불빛(가로등·창문)과 같은 개수 단위, 그림자 끔 |
| 점등 장 수 | 5장 25단계 끝 | STORY.md 5장 5단계 「이후 밤마다 등대가 돈다」 |

## 5. 조각 나누기
1. 조사: 「섬 한가운데 언덕」이 어느 존의 어느 좌표인지(`SnareZoneRules`·존 지형 높이)를 오프라인 캡처로 정하고 STATUS 에 적는다. 탑을 세울 자리가 없으면 🔴 `질문`.
2. 레퍼런스 시트(`reference-sheet`) + 탑 메시 Blender 스크립트와 정면·옆 캡처(`new-visual`) — 겉모습은 우리 것(Reference 6절 「다른 점 3」).
3. 코드: 탑 액터 세우기 + `bDone` 이면 불빛 켜는 규칙 함수(`SnareStory::` 에 순수 함수, 시험 `Snarehaven.Story.Lighthouse.*`) — 낮밤 규칙은 기존 `USnareDayNightSubsystem` 재사용, 새 낮밤 코드 없음.
4. 빛줄기 회전(20초) + 오프라인 밤 캡처 스위치(`-SnareStoryAt=25` 를 `bDone` 답으로 쓰는 길 포함) — 불 켜진 밤·꺼진 낮·5장 전 3장.
5. 빈 길 0 단정: 5장 전 계정에서 불이 한 개도 안 켜진다는 시험.

### 조각 1 조사 결과 (#1280)
- 월드는 평지다: 안개뿔 스폰 로그 20줄 전부 바닥 Z=45(`Saved/M96/*.log` 「이야기 동물 스폰 … 자리」), `fogbuck_1191.png` 도 눈밭 평지. **「언덕」은 지형이 아니라 이름뿐** — 탑 높이로 언덕 느낌을 낸다.
- 자리(🟡): 설원 칸(`zone.snow`, `create_data_tables.py` 2604행) 가운데 `(22400, -7400)` — 안개뿔이 서는 칸이라 5장 22~23단계 「등대 언덕」과 같은 곳이다. 바닥 Z 는 코드에서 `ProjectCellToGround` 로 맞추고, 나무·바위에 겹치면 근처 빈 칸으로 비킨다(조각 3). 레벨 파일은 안 고친다.
- 🔴 질문 없음 — 새로 정하는 건 좌표 하나뿐이고 틀려도 상수 한 줄.

- **정정(#1283):** `(22400, -7400)` 은 바다였다(`SnarehavenZoneRegionTest` 도 바다라고 단정) — 칸 가운데가 뭍이 아니다. 탑 자리를 `islands.land_point(22400,-7400,zone='snow',margin=2500)` 값 `(19416, -4736)` 로 옮김(설원 뭍, 해안 25m 안쪽).

- 1층: 빌드 + `check_conventions.py`
- 2층: `Snarehaven.Story.Lighthouse.*` — `bDone` 아님 → 불 0, `bDone` + 밤 → 켬, `bDone` + 낮 → 끔, 20초 주기 회전각
