## 1. 합격 기준 (한 문장)
> 게임 카메라 전수 착용 캡처(가까이·앞옆뒤, `-SnareWearAll`)의 머리 칸에서 **한 화면에 같은 실루엣이 셋 이상 나란히 있지 않고**, 처음 보는 사람이 이름(도넛·토끼·카우보이…)을 그림자만 보고 맞힐 수 있다 — 숫자 잣대: `hat_silhouette_check.py` 「같은 실루엣 셋(삼각)」 에 든 꾸미기 **0**.

## 2. 플레이어가 보는 것
- 입력: 옷장·상점·꾸미기 상자에서 모자 하나를 입는다(바뀌는 것 없음).
- 화면: 머리를 덮는 둥근 돔에 색만 바뀐 모자(지금) → 이름이 뜻하는 꼴. 동물 귀·뿔은 실루엣 위로 솟고, 과일·음식은 그 물건 모양, 챙 모자는 챙 폭·운두가 서로 다르고, 비니·두건은 머리에 붙는 얇은 껍질.
- 실패·예외: 모자 아랫단은 그대로 눈썹선(#1352 `HatBrimLift`·시험 `BrimAboveEyes`) — 꼴을 바꿔도 눈을 덮지 않는다. 머리 살·머리카락이 모자를 뚫지 않는다(시험 `NoHeadPenetration`). 윗면이 열린 「고리」 계열은 행 `bHatKeepsHair` 참.

## 4. 계열 틀 5개 (공통 함수 — 57번 따로 빚기 금지)
새 파일 `tools/blender/hat_families.py` 에 틀 함수 5개를 두고, `hats_more_make.py` 의 행은 **계열 + 치수 몇 개 + 장식**만 고른다. 장식(귀·뿔·잎·눈·부리)은 기존 `Builder` 의 `blob`·`plate`·`tube`·`sweep` 그대로. 아랫단 높이·안쪽 면(`inner`)·머리 틈 `G` 는 다섯 틀이 같은 함수 하나(`seat`)를 쓴다 — 그래야 #1352·#1355 시험이 계열마다 따로 깨지지 않는다.

| 계열 | 틀 함수 | 꼴을 정하는 치수 | 실루엣 목표 |
|---|---|---|---|
| A 비니·두건 `beanie` | 머리에 붙는 얇은 껍질(두께 ≤ 1.4cm 상당) + 접은 테 | 테 높이 · 꼭대기 부풂 | 머리 윤곽 그대로 — 꼴은 **장식이 솟아서** 만든다(귀·뿔이 머리 꼭대기 위로 머리 높이의 0.4 이상) |
| B 챙 `brim` | 운두(원통·원뿔·돔) + 둘레 챙 | 운두 높이 · 운두 모양 · 챙 폭 · 챙 처짐/말림 · 앞뒤 비대칭 | 챙 폭·운두 높이 조합이 행마다 다름 — 같은 (높이/폭, 챙 폭) 칸 둘 이상 금지 |
| C 캡 `cap` | 납작한 돔 + 앞챙 하나 | 앞챙 길이 · 돔 높이 · 뒤 조임 | 옆에서 앞으로 길게 나온 챙이 보임 |
| D 물건 `object` | 얕은 받침(아랫단 띠, 머리 위 1/3 만) + 위에 물건 꼴 | 물건 꼴 함수(고리·층 원통·타원체·원뿔·상자·쐐기·탑) | **머리 돔이 아니라 물건 꼴이 실루엣** — 받침은 이마~정수리만, 물건이 그 위로 머리 높이의 0.5 이상 |
| E 고리 `ring` | 윗면 없는 띠(왕관·화관) | 띠 높이 · 갈래 수 | 윗면이 열림 — 행 `bHatKeepsHair` 참(DESIGN 3.5 기준 그대로: 돔 없이 띠만) |
