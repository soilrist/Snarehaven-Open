# 기능 명세: 색 변종 펫 · 주간 우두머리 (M21-07)

- 상태: 초안 (루프#328 — 숫자·구조 전부 🟡, INBOX `확인(루프#328)`)
- 마일스톤: M21 · 범위(커밋 scope): `hunt`(변종 스폰·우두머리) · `backend`(서버 표·판정) · `ranch`(생산 배수) · `ui`(도감 칸)
- DESIGN 연결: `DESIGN.md` 10.6 「변종·우두머리 확률 고지」(숫자 원본) · 3.1 포획 · 3.2 목장 생산 · 8.1 위험구역 · 8.5 도감
- ROADMAP 원문: M21-07 「종마다 변종 3%(12종×1, 생산 ×1.5, 도감 변종 칸 12) · 위험구역 주 1회 우두머리(HP 5배, 전용 모자 10%). 확률은 서버 표 = 클라 표 = DESIGN 10.6 고지 표. 합격: 데이터 시험 + 스폰 1만 회 3%±0.5%p + 도감 캡처.」

## 1. 합격 기준 (한 문장)
> 사냥 맵에 서는 동물 100마리 중 약 3마리가 색이 다른 변종이고, 그것을 잡으면 가방에 「○○ 변종 펫」이 들어와 목장에 올리면 같은 종보다 1.5배 빨리 생산하며 도감 「변종」 칸이 하나 찬다. 위험구역에는 주 1회 HP 5배 우두머리가 서고, 잡은 사람은 그 주에 한 번 10% 확률로 전용 모자를 받는다.

## 2. 플레이어가 보는 것
- **변종**: 평소처럼 사냥 맵을 돌다 몸 색이 다른 동물을 본다(머리 위 이름 카드에 `변종` 딱지). 잡는 방법·HP·행동은 같은 종과 같다. 포획하면 알림 `○○ 변종 펫을 얻었다`. 목장 칸에 올리면 칸 카드에 `변종` 딱지, 주기가 짧다. 도감에 `변종` 탭 12칸.
- **우두머리**: 위험구역(8.1)에 늑대 5마리와 함께 큰 늑대 한 마리(몸 1.5배, 이름 카드 `우두머리`). HP 5배라 여럿이 같이 때리게 된다(M21-06a 같이 잡기 드롭이 그대로 붙는다). 쓰러뜨리면 일반 드롭 + 서버 굴림 결과(모자 당첨이면 알림).
- 실패·예외: 변종을 처치하면(포획 아님) 일반 드롭만 — 변종 전용 드롭 없음. 우두머리는 포획 불가(펫이 아니다). 이번 주에 이미 우두머리 보상을 받은 사람은 서버가 `already_claimed` 로 답하고 일반 드롭만 받는다.

## 5. 조각 나누기
1. **M21-07a 변종 스폰·포획(호스트)** — 스폰마다 `VariantChance` 굴림 → 복제 `bVariant` · 색 · 이름 카드 딱지 · 포획 시 `VariantPetItemID` 를 대기열에(`HandleAnimalCaptured`). 아이템 12행. 2층: 시드 고정 1만 회 스폰 3%±0.5%p · 변종 포획 → 변종 펫 아이템.
2. **M21-07b 변종 펫 서버** — `ClaimLoot` 가 변종 펫 12종을 받는다 · `RegisterPet`/`RemovePet` 가 변종 펫을 같은 종으로 읽고 칸에 `variant: true` · 생산 주기 ÷1.5 · 도감 `variant` 카테고리 12칸(`item.pet_<종>_variant` 그대로 칸 ID) — 상인·해금 보상 계산(`codexProgress` rewards)엔 안 넣는다. node 시험.
3. **M21-07c 변종 화면** — 도감 `변종` 탭(12칸, 서버 `categories.variant`) · 목장 칸 카드 `변종` 딱지 · 가방 카드 이름. 2층 + 3층 도감 캡처(ROADMAP 합격 줄).
4. **M21-07d 우두머리 서버** — CloudScript `ClaimBoss {}`: 이번 주(UTC 월요일 경계) 처음이면 `BOSS_HAT_CHANCE` 굴림(이미 모자가 있으면 당첨 = 코인 150), 기록 `bossWeek`, 아니면 `already_claimed`. 모자는 가방 자리 없으면 `inventory_full`(주 기록 안 남김). node 시험(1만 회 10%±1%p · 같은 주 두 번째 · 다음 주).
5. **M21-07e 우두머리 모자** — `item.chief_hat` 행·메시·아이콘(새싹 모자 #0400 과 같은 길), 효과 없음(겉모습만).
6. **M21-07f 우두머리 스폰(호스트)** — 상시 위험구역(8.1)이 채울 때 서버 월드에 우두머리가 없으면 한 마리 더(늑대 행 + HP ×5 + 몸 ×1.5) · 처치에 데미지를 넣은 사람마다(M21-06a 창) `ClaimBoss` · 결과 알림. 재생성은 구역 재생성(300초)과 같다 — 보상은 서버가 주 1회로 막으니 몸은 다시 서도 된다. 2층: HP = 늑대 ×5 · 처치 → 명중자 수만큼 호출.
7. **M21-07g 고지 표** — 상자 확률 고지(10.6) 화면과 같은 꼴로 도감 변종 탭·위험구역 안내에 `변종 3%`·`우두머리 모자 10% (주 1회)` 한 줄씩. 2층: 서버 표 = 클라 표 = DESIGN 표 글자 맞대기(`Snarehaven.Codex.Hunt.MatchesServer` 와 같은 꼴).

## 7. 하지 않을 것
- 변종 전용 드롭·변종 전용 HP·행동 — 원문에 없다.
- 우두머리 전용 메시·클립 — 늑대 메시를 키운다(새 에셋 0).
- 종마다 다른 변종 확률 — 원문이 「3%」 하나다.
- 우두머리 모자의 효과 — 「전용 모자」 는 새싹 모자처럼 겉모습만(13.5 효과 표에 빈 칸).
- 변종 확률을 서버가 굴리는 것 — 스폰은 호스트 몫이고 포획 지급도 이미 호스트 판정(`ClaimLoot` 한도 안)이다. 부풀리기는 `ClaimLoot` 한도·간격이 막는 만큼만 막힌다(ponytail 메모와 같은 수준).
