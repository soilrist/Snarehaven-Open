# 기능 명세: 안개뿔(흰 사슴)과 등대 불빛 고리

- 상태: 초안
- 마일스톤: 메인 스토리 ⑤ · 범위(커밋 scope): `story`
- DESIGN 연결: 의뢰 줄기 절 · `docs/STORY.md` 4절 5장 3·4단계, 5절 · INBOX 지시 「메인 스토리 퀘스트」 ⑤

## 1. 합격 기준 (한 문장)
5장 23단계에서 「안개뿔」이라는 특별한 흰 사슴 한 마리만 포획 대상으로 세어지고, 24단계에서 그 안개뿔이 목장에서 수확을 한 번 내면 단계가 넘어간다.

## 2. 플레이어가 보는 것
- 화면: 등대 언덕에 흰 사슴이 선다(순록 몸체에 흰 색, 이름표 「안개뿔」). 공격하지 않고 도망만 친다. 잡으면 목장 맨 앞자리에 선다.
- 등대 불빛 고리: 장 끝마다 HUD 구석 고리가 1/5씩 켜진다(`CompletedChapter` 값 그대로).
- 실패·예외: 안개뿔을 놓치면 다시 선다(재생성). 이미 잡았으면 서지 않는다.

## 3. 숫자
| 이름 | 값 | 근거 |
|---|---|---|
| 안개뿔 체력 | 순록의 2배 = 200 | 5장 보스급. 큰 종 최대 단계(200)와 같아 새 숫자가 아님 🟡 |
| 안개뿔 공격 | 0 | STORY.md 「공격하지 않고 도망만」 |

## 4. 데이터·에셋

| UI | HUD 고리 위젯 | 만들 것 |

## 5. 조각 나누기
1. 서버: 포획 기록에 종 id 를 남겨 23단계가 `fogbuck` 만 세게 한다(시험).
2. `fogbuck` 행 + 등대 언덕 한 자리 스폰(이미 잡았으면 안 섬). **한 바퀴에 안 들어가 셋으로 쪼갠다 (#1183 점검).**
   - 2a. `AnimalRow` 에 「이야기 종」 칸(`bStorySpecies`)을 더하고, 분산 스포너 풀(`AAnimalSpreadActor::MakeSpawnPool`)·변종 굴림·도감 12종 집계에서 뺀다. 이유: 새 종 행이 그냥 서면 `SnarehavenVariantBossDisclosureTest`(기본 플레이 종 12)·`SnarehavenCodexScreenTest`(변종 칸 12·도감 칸 수)·서버 도감 종 목록이 깨지고, 평원·설원에 무작위로 선다. 시험: 이야기 종은 풀에 0, 12종 단정은 그대로.
   - 2b. 생성기 `create_data_tables.py` 에 안개뿔 한 줄(순록 폴더 몸체 재사용, 체력 200, 행동 `Flee`, 공격 0, 펫 행 `item.pet_fogbuck`)과 흰색 칸을 더하고 에디터로 표를 다시 만든다. 변종 펫 행은 만들지 않는다(`VariantChance` 0).
   - 2c. 등대 언덕 한 자리 스폰 — 레벨 파일은 텍스트로 안 고치므로 존 스포너가 아니라 코드 쪽 「이야기 동물 스포너」(이미 `fogbuck` 을 잡았으면 안 섬, 놓치면 다시 섬) + 오프라인 캡처 스위치.
3. 24단계: 목장 수확을 안개뿔로 한정(서버 판정).
4. HUD 등대 고리 1~5/5.

## 6. 검사 방법
- 1층: 빌드 + `check_conventions.py`
- 2층: `Snarehaven.Story.*` 에 단계 23·24 판정 시험 추가
- 3층: 등대 언덕 오프라인 캡처 + 고리 5장(감독)
