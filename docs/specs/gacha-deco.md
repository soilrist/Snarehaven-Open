# 기능 명세: 가챠 목장 데코 5종 (목장 겉모습 스킨)

- 상태: 초안 (루프#520 작성 · 🟡 INBOX `확인` — 감독 검수 대기)
- 마일스톤: M35 · 범위(커밋 scope): `ranch` (서버 줄은 `backend`)
- DESIGN 연결: `DESIGN.md` 10.3(풀 = 코스메틱만, 「목장 데코 아이템 (건물 외관, 울타리 스타일 등)」) · 10.9(목장 동물 꾸미기 — 같은 판정 길) · 3.2(목장) · `docs/GACHA_DISCLOSURE.md` 「목장 데코」 5줄
- ROADMAP 조각: M35-05(이 명세) → 아래 5장 조각 a~d

## 1. 합격 기준 (한 문장)
> "뽑기로 얻은 목장 데코를 배낭에서 「목장에 적용」 하면 서버가 내 목장 기록에 그 종류(울타리·바닥·헛간·배경) 한 칸을 적고, 내 목장(`L_Ranch`)에 들어가면 그 종류의 겉모습만 바뀐다 — 생산·칸 수·충돌·길은 하나도 안 바뀐다."

**왜 「설치물」 이 아니라 「겉모습 스킨」 인가 (🟡).** 공개 문서 이름이 전부 「…스킨」·「…타일」 이다(나무 울타리 **스킨** · 흙길 **타일** · 돌담 울타리 **스킨** · 붉은 지붕 헛간 **스킨** · 별빛 목장 배경 **스킨**). 설치물(8.11 `Placeable`)로 만들면 ① 배낭 칸·설치 자리·충돌을 새로 따져야 하고 ② 이미 있는 `item.fence_wood`(작업대 제작 울타리)와 같은 물건이 둘이 된다. 목장에 이미 서 있는 울타리·돌길·닭장·하늘의 **메시·재질만 바꾸는 것**이 가장 작은 쓰임이고, 충돌·길을 안 건드리므로 갇힘이 생기지 않는다.

## 2. 플레이어가 보는 것
- 입력: 배낭에서 데코 칸을 누르면 상세 판에 **「목장에 적용」**(이미 적용 중이면 **「적용 해제」**) 버튼 하나. 배낭 칸 보이기는 M35-06 이 만든다 — 이 명세는 그 상세 판에 버튼만 더한다.
- 화면: 목장에 들어가거나(이미 목장이면 응답 직후) 그 종류의 겉모습이 바뀐다. 결과 알림 한 줄 「〈이름〉 을(를) 목장에 적용했다」.
- 실패·예외:
  - 같은 종류 둘(나무 울타리·돌담 울타리)은 **한 칸** — 새 것을 적용하면 옛 것은 자동으로 풀린다(아이템은 그대로 배낭에 있다).
  - 데코는 **소비되지 않는다**(스킨 = 해금). 가챠 아이템이라 배낭 칸을 안 차지해 가득 찬 가방에도 적용·해제가 된다(10.9 펫 의상과 같음).
  - 가진 적 없는 데코 → 서버 `not_enough_items`. 모르는 ID → `bad_args`.
  - 목장 잠김(유지 끊김) 중에도 적용 가능 — 겉모습은 생산과 무관.
  - 다른 사람 목장에 놀러 간 경우: 그 집 주인의 데코가 보인다(호스트의 `GetBaseState`) — 게스트가 바꿀 수는 없다.

|---|---|---|---|

## 4. 데이터·에셋 (새 메시 0 — 이미 반입된 것만)
| 경품 ID | 종류(`kind`) | 바뀌는 것 (`L_Ranch` 액터) | 쓸 에셋 | 있음/만들 것 |
|---|---|---|---|---|
| `gacha.deco_wood_fence` 나무 울타리 스킨 | `fence` | 앞·옆 울타리 `FenceFront_*`·`FenceLeft_*`·`FenceRight_*` + 칸 난간 `Poles_*` 메시 | `SM_Building_Fence_01`(Quaternius 농장 울타리 — 지금 널판 `Fence_02` 와 다른 말뚝 모양) | 있음 |
| `gacha.deco_stone_fence` 돌담 울타리 스킨 | `fence` | 위와 같은 액터 재질 | `SM_Building_Fence_02` + `MI_Building_PathStone`(돌길 회색) — 돌담 전용 메시가 없어 **재질 자리표시** 🟡 | 있음 |
| `gacha.deco_dirt_path` 흙길 타일 | `path` | 대문 돌길 `Path_Gate` + 칸 발판 `Planks_*` 재질 | 새 MI `MI_Building_PathDirt`(부모 = 기존 무광 부모, 흙색 하나) | **만들 것**(MI 1개) |
| `gacha.deco_red_barn` 붉은 지붕 헛간 스킨 | `barn` | 마당 닭장 `Coop_01` 메시 | `SM_Building_Barn_02`(작은 헛간, Quaternius — 반입만 되고 레벨에 없음) · 지붕 슬롯 붉은 MI | 메시 있음 · MI **만들 것** |
| `gacha.deco_starlight_bg` 별빛 목장 배경 스킨 | `sky` | `RanchSun`·`RanchSky` 세기·색 (3장 값) | 없음(빛 값만). 별 입자는 이번 범위 밖(7장) | 있음 |

- 표: `DT_ItemTable` 에 `RanchDeco` 행 5개(생성기 `tools/unreal/create_data_tables.py` 의 `GACHA_RANCH_DECO_ITEMS` — M35-04 `GACHA_PET_COSMETIC_ITEMS` 와 같은 짜임). 행에 `DecoKind`·메시 경로·재질 경로·빛 배수.
- 액터 찾기: 이름 패턴이 아니라 **액터 태그**로(`RanchDeco.Fence` · `RanchDeco.Path` · `RanchDeco.Barn` · `RanchDeco.Sky`) — `tools/unreal/setup_ranch_buildings.py` 가 세울 때 태그를 붙인다(PROMPT ③-12, 이름이 바뀌어도 안 깨지게).
- 원래 겉모습으로 돌아가기: 적용하기 전 메시·재질·빛 값을 컴포넌트가 처음 한 번 기억해 두고, 해제·다른 종류 적용 때 그 값으로 되돌린다.
- **헛간 크기 주의:** `Barn_02` 와 `Coop_01` 은 크기가 다르다. 메시만 바꾸면 충돌이 커져 마당 길이 막힐 수 있다 → 헛간 스킨은 **충돌을 끈 겉모습 메시를 같은 자리에 겹쳐** 보이게 하고 원래 `Coop_01` 은 숨기기만(충돌 그대로) 한다. 폭은 `Coop_01` 바운딩 폭에 맞춰 줄인다(구현 조각이 잰 값을 표에).

## 5. 조각 나누기 (루프가 채움, 사람이 확인)
1. **M35-05a 서버** — `cloudscript_main.js` 에 `GACHA_RANCH_DECOS`(ID → kind 5줄) · `SetRanchDeco {itemId}`(빈 문자열 + `kind` = 해제) — 가졌는지 `countOf ≥ 1` 만 보고 `ranchMeta.deco[kind] = itemId`, 소비 0 · `GetBaseState` 응답에 `ranchDeco` 와 「배낭에 없어진 데코는 빼고」 보냄. 시험: 적용·같은 종류 바꾸기·해제·안 가진 것 거절·가득 찬 가방에도 됨·인벤토리 변화 0·생산 값 변화 0. 역검증: 사본에서 소비 1 로 → 실패.
2. **M35-05b 표·레벨 태그** — `DT_ItemTable` `RanchDeco` 행 5 + MI 2개(흙길·붉은 지붕) + `setup_ranch_buildings.py` 태그 붙이기(커맨드릿, 에셋 텍스트 편집 0). 2층: 행 5개 = 공개 문서 5줄, 태그 붙은 액터 수(울타리·난간·바닥·닭장·빛) 0 아님.
3. **M35-05c 클라 적용** — 목장 레벨의 기존 `URanchInteractComponent` 옆에 작은 적용 함수(`ApplyRanchDeco(World, DecoMap)`, `ApplySlotVisibility` 와 같은 정적 모양) + `GetBaseState` 받을 때 부름. 2층: 종류마다 적용 → 태그 액터 메시·재질이 표 값 · 해제 → 처음 값 · 충돌·숨김 칸(잠긴 칸)은 그대로 · `HouseFurniture.WalkInsideAndOut`·`ShopPierLevel.CustomerReachesCounter` 길 시험 다시 통과.
4. **M35-05d 배낭 버튼** (M35-06 뒤) — 데코 칸 상세 판 「목장에 적용/적용 해제」 → `SetRanchDeco` 요청, 응답 뒤 `GetBaseState` 로 다시 그림(규칙 8 — 응답 전에 겉모습을 바꾸지 않는다). 3층: 목장 게임 카메라 캡처 — 적용 전 1장 · 울타리·바닥·헛간·배경 각 1장.

## 7. 하지 않을 것
- 새 메시 만들기·반입(돌담 전용·별 하늘 돔) — 시트 반입 때 표의 메시 경로만 바꾸면 된다.
- 별 입자·밤 소리·시간대 바꾸기.
- 사냥터·거점 바깥(목장 밖) 겉모습.
- 데코를 설치물로 따로 놓기(8.11 `Placeable`) — 1장 「왜」 참고.
- 게스트가 남의 목장 데코를 바꾸기.
- 옷장·꾸미기 상자 풀에 데코 넣기(뽑기 전용 — 10.9 펫 의상과 같음).
