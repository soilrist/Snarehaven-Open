description: 사람이 한마디로 게임이나 큰 기능을 만들라고 할 때 사용("이런 게임 만들어", "~같은 거 만들고 싶어", "이거 만들어!", "새 기능: ~"). 한마디를 설계서·질문 묶음·로드맵으로 바꾸고 루프가 바로 일할 수 있게 준비한다.
---

목표: 사람이 한 번만 대답하면 루프가 몇 시간 혼자 일할 수 있는 상태를 만든다.

1. `docs/conventions/Autonomy.md` 를 읽는다. (무엇을 혼자 정하고 무엇을 묻는지)
2. **있는 것부터 읽기** — 프로젝트에 이미 기획 문서·코드·에셋·README 가 있으면 먼저 훑어서(grep·목록) 그걸 출발점으로 삼는다. 이미 정해진 건 다시 묻지 않는다.
3. **이해하기** — 한마디에서 뽑는다: 장르·**주 레퍼런스 게임 하나**·느낌·플랫폼·규모. 레퍼런스가 없으면 첫 질문으로 정한다 (🔴). 정해지면 웹에서 조사해 시스템·콘텐츠 종류·화면 목록·아트 규격을 뽑는다 (`Reference.md` §1 — 복제 자세·§5 전부 규칙은 거기).
   - **레퍼런스를 모르거나 자료가 안 나오면** (조사해도 시스템·화면을 못 채움): 지어내지 않는다. ROADMAP 맨 앞에 `[!] 사람: 레퍼런스 캡처·링크를 _Source/reference/<게임>/ 에 넣기` 한 조각 + INBOX `질문` 하나로 요청하고, 그동안은 장르 관례로 채우되 전부 `〔가정: 레퍼런스 미확인〕` 표시. **레퍼런스 자체를 다시 묻지 않는다** — 사람은 이미 정했다. 자료가 오면 루프가 `[!]` 조각을 풀고 시트부터 다시 만든다.
4. **설계서 초안** — `docs/DESIGN.md` 틀을 채운다. 신호등(`Autonomy.md`)대로: 🟢 채움 · 🟡 무난한 해석 + `〔가정: …〕` · 🔴 방향은 비워 질문 목록에. §5 는 레퍼런스 종류 전부(`Reference.md` §1), §6 숫자는 근거와 함께 채움(`DataDriven.md` 3), §7·§8 은 레퍼런스 대응 화면·규격, M0·M1 의 화면·캐릭터는 `docs/reference/<대상>.md` 시트까지(`Reference.md` §2).
5. **질문 묶음 1회** — 사람에게 한 번에 보낸다 (`Autonomy.md` "묻는 방법"): 최대 5개, 선택지 2~4개 + 추천 + "고르면 무엇이 달라지나" 한 줄. 숫자는 묻지 않는다 (§6 표를 보여 주고 "바꿀 게 있으면 말해 줘"). **질문 앞에 "지금 가정한 것" 3~5줄 요약**을 보여 줘서 틀린 가정을 사람이 바로 잡게 한다.
6. 답을 받으면 DESIGN 에 반영하고 `〔가정〕` 을 확정/수정한다. 결정은 `docs/decisions/` 에 한 장씩.
7. **로드맵** — `docs/ROADMAP.md` 를 M0(뼈대)~Mn 으로 쪼갠다. 조각마다 ID(`M1-03`)와 합격 기준 한 줄. 조각 하나 = 커밋 하나 크기(10분 안팎). 첫 마일스톤은 "화면에서 뭔가 움직인다"가 빨리 나오게. §5 의 콘텐츠 종류마다 마일스톤 하나씩(`Reference.md` §1 — 없으면 kickoff 미완). 사람만 할 수 있는 조각은 `[!] 사람:` (`Autonomy.md` 🔴 6). 마일스톤마다 끝에 두 조각: `처음 하는 사람 통 플레이` 와 `[!] 사람: 🎮 5분 해 보기 — 계속 / 고쳐` (ROADMAP 머리말, `PlayerEye.md`).
8. 복잡한 조각은 `docs/templates/FeatureSpec.md` 로 명세를 `docs/specs/` 에 만든다 (M0·M1 것만. 뒤는 루프가 그때 만든다).
9. `docs/STATUS.md` "지금 상태"를 채우고, INBOX 에 남은 `질문`·`확인` 을 정리한다.
10. 사람에게 보고: "설계서·로드맵 준비됨 / 루프가 먼저 할 조각 3개 / 아직 답 필요한 것" — 5줄 이내. 루프 켜기(`loop/ctl.sh on`)는 사람이 "켜"라고 할 때 감독이 한다.

커밋은 `docs(design): 킥오프 초안`, `docs(roadmap): M0~M3 조각 나누기` 처럼 나눠서, 사람 확인 후.
이 파일과 규칙 문서 내용이 다르면 규칙 문서를 따른다.
