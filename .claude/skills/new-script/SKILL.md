name: new-script
description: 새 스크립트·기능 코드를 만들어 달라는 요청("~하는 스크립트 만들어줘", "~기능 추가해줘")을 받았을 때 사용. 계획 승인 → 작성 → 규칙 검사 순서로 만든다.
---

1. `docs/conventions/CodingStyle.md`, `docs/conventions/FolderStructure.md` 를 읽는다. 콘텐츠(몬스터·아이템 등)면 `DataDriven.md` 도.
2. 비슷한 기존 코드가 있는지 grep 으로 먼저 찾는다. 있으면 새로 만들지 않고 고치는 계획을 세운다.
3. 계획을 보여 주고 승인받는다 (**루프 일꾼이면** 승인 대신 STATUS 에 계획 한 줄 기록 후 진행):
   - 스크립트 이름·네임스페이스·둘 폴더
   - 필드·메서드 목록과 각각 하는 일
   - 필요한 데이터(SO)와, DESIGN §6 에 아직 없는 숫자 목록(+ 어떤 근거로 정할지)
   - 새로 만들 폴더가 있으면 그 폴더
4. 요청받은 만큼만 작성한다. 숫자는 데이터로 빼고, 없으면 DESIGN §6 에 근거와 함께 먼저 적는다 (`DataDriven.md` 3).
5. `python3 tools/check_conventions.py --changed` 와 엔진 콘솔/로그의 컴파일 에러를 확인한다 (`docs/checks/<엔진>.md`).
6. 감독/수동 작업이면 `convention-checker` 에이전트에 만든 파일을 점검받고 결과를 같이 보고한다.
7. 씬 오브젝트에 붙이는 건 에디터 변경이다. 감독·수동 작업이면 승인 전엔 하지 않고 어디에 붙이면 되는지만 안내한다. **루프 일꾼이면 이번 조각 범위 안에서 엔진 MCP 로 진행**한다.

이 파일과 규칙 문서 내용이 다르면 규칙 문서를 따른다.
